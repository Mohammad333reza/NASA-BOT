# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

Built a responsive web app using React.js, Node.js, and the NASA Open API to display real-time space and astronomy data, including daily images and mission details. Integrated API requests for live data and deployed on Netlify with a modern UI/UX design.
This setup gives a simple way to make React work with Vite, including HMR (Hot Module Replacement — live updating without reloading) and ESLint (for code checking).
Note: The project connects directly to the live NASA API; occasional downtime may occur when the external API is updated.

The NASA API integration is currently inactive due to NASA’s API key and service maintenance issues.
